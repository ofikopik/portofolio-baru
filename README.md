# Portofolio Taufik

Portofolio pertama saya, dibuat dengan HTML dan CSS sebagai latihan.

## Halaman

- `portofolio.html`: beranda
- `perkenalan.html`: tentang saya
- `tujuan.html`: alasan membuat portofolio
- `kontak.html`: cara menghubungi saya
- `porto.css`: gaya tampilan untuk semua halaman

## Cara melihat

Buka `portofolio.html` di browser.
